# GEA8811 · 인공지능입문 실습판

2026학년도 2학기 **인공지능입문(GEA8811)** 인터랙티브 실습 공간입니다.

## 이 공간에서 하는 일

이 저장소는 강의자료를 제공하는 곳이 아니라, 수업에서 배운 내용을 **직접
눌러 보고, 예측하고, 실험하고, 결과를 확인하는 인터랙티브 실습**을 위한
공간입니다.

강의자료와 수업 안내는 학교 LMS에서 확인합니다.

## 시작하기

👉 **[인터랙티브 실습 시작하기](./index.html)**

`index.html` 하나에서 주차별 실습을 선택할 수 있습니다.

## 실습 방식

각 주차는 가능한 한 다음 흐름으로 구성되어 있습니다.

1.  **먼저 예측하기**
2.  **직접 해 보기**
3.  **무엇이 보였는지 확인하기**
4.  **확인 문제로 이해 점검하기**

정답을 외우는 것보다 **직접 조작하면서 AI의 작동 방식을 이해하는 것**을
목표로 합니다.

## 외부 도구

일부 실습은 브라우저에서 외부 도구를 직접 사용합니다.

예를 들어 머신러닝 실습에서는 **Google Teachable Machine**을 사용하여
코딩 없이 이미지 분류 모델을 만들어 봅니다.

외부 도구를 사용할 때에는 각 주차의 안내를 따라 주세요.

## 개인정보 주의

실습에 사진이나 데이터를 사용하는 경우 **얼굴, 학생증, 개인 문서 등
개인정보가 포함된 자료는 사용하지 않습니다.**

가능하면 책, 펜, 컵 등 개인정보가 없는 대상을 사용하세요.

## 진행 기록

실습 완료 기록은 학생의 **현재 기기 브라우저에만 저장**됩니다.

-   과제 제출용 기록이 아닙니다.
-   다른 기기나 브라우저에서는 이어지지 않을 수 있습니다.
-   브라우저의 저장 데이터를 삭제하면 진행 기록도 사라질 수 있습니다.
